# MAX31865 + 三线 PT100

本例使用 430 Ω 参考电阻，每 1 秒通过 UART 输出一次摄氏温度。

## 接线与参数

| MAX31865 | S32K144 |
|---|---|
| SCK | PTB14，LPSPI1_SCK |
| SDO / MISO | PTB15，LPSPI1_SIN |
| SDI / MOSI | PTB16，LPSPI1_SOUT |
| CS | PTC9，GPIO 输出，空闲为高 |
| GND | 共地 |

SPI 使用 Mode 1、500 kHz、8 位、MSB 优先。模块供电按已确认的 3.3 V 接线。
板载 W25Q64 与它共用 SPI1，因此 SPI.c 将 W25Q64 的 PTB17 片选保持高电平。
本例不需要连接 DRDY。模块上的三线制焊盘/跳线也需要与三线 PT100 接法一致。

串口助手设置：**115200、8 数据位、无校验、1 停止位、无流控**。
生成的 UART 配置当前是 9600，应用层 uart.c 会覆盖为 115200；不需要手改生成文件。

## 从哪里开始读代码

1. `Sources/main.c`：初始化时钟、引脚、UART、MAX31865、LPIT；到期后读取并打印。
2. `Sources/SPI.c/.h`：初始化 LPSPI1，用 PTC9 控制片选；一笔传输包含寄存器地址和全部数据。
3. `Sources/MAX31865.c/.h`：设置三线制及 50 Hz 滤波，开启偏置，启动单次转换，读取 ADC 和故障寄存器，将电阻换算成温度。
4. `Sources/LPIT.c/.h`：新增 `LPIT_HasElapsed()`，返回本周期是否到期。原来的 `LPIT_Process()` 仍可用于发送固定字符串。

主循环的调用关系：

```text
LPIT 每秒到期
  → MAX31865_ReadTemperature()
    → SPI_Transfer() 读写寄存器
    → R = raw × 430 / 32768
    → PT100 Callendar–Van Dusen 方程求温度
  → 格式化字符串
  → Uart1_Send()
```

每次读取大约需要 80 ms（偏置稳定 10 ms，转换等待 70 ms）。LPIT 在这期间一直计时，
所以正常情况下输出间隔约 1 秒，不会变成“读完温度再等待 1 秒”。第一行在启动后约 1.08 秒出现。
周期精度仍受 MCU 时钟误差和电脑串口接收时间戳影响。

温度以百分之一摄氏度保存，例如 `2534` 表示 `25.34 C`。使用整数格式化，
无需开启 printf 浮点支持。显示两位小数不代表测温准确度达到 0.01 ℃。

## 修改参数

在 main.c 顶部修改：

```c
#define PT100_RREF_OHMS 430.0f
#define TEMPERATURE_PERIOD_US 1000000U
```

`1000000U` 微秒等于 1 秒。当前是阻塞式单次转换，周期应大于转换和串口输出耗时；
例如 500 ms 可用，不适合直接改成 10 ms。

## 运行与故障

在 S32DS 选中工程按 F5 刷新，然后编译、下载运行。正常输出示例（数值仅为示例）：

```text
Temperature: 25.34 C
```

异常示例：`MAX31865 error=3 fault=0x80 raw=32767`。

配置读回失败会单独打印，例如 `MAX31865 error=2 cfg=0xFF expected=0x11`。
`cfg` 是实际读回值，`expected` 是期望值：初始化为 0x11，转换后为 0x91。
此时还未读取 RTD 和故障寄存器，因此不再打印容易误解的 `fault=0 raw=0`。
读回 0x00 或 0xFF 时优先检查模块供电、共地和 SPI 接线，不能仅凭该值判定芯片损坏。

| error | 含义 |
|---|---|
| 1 | SPI 初始化或传输失败/超时 |
| 2 | 配置寄存器读回不符，优先检查供电、CS、MISO 和 SPI 模式 |
| 3 | MAX31865 报告测量故障，结合 fault 检查 PT100 接线 |
| 4 | ADC 达到极限或电阻超出标准 PT100 的 -200～850 ℃范围 |
| 5 | 未初始化成功，或等待后转换仍未完成 |
| 6 | 函数参数不合法 |

fault 是寄存器 0x07 原值：0x80/0x40 为高/低阈值故障，0x20/0x10 涉及参考输入，
0x08 涉及 RTDIN-，0x04 为过压/欠压；具体电气判据见数据手册。
出错后程序会在下一周期重试，不会把失败的数据打印成有效温度。

在 `error=3` 或 `error=4` 时，程序还会执行一次约 30 ms 的手动故障检测，输出
`test=... wiring=0x... cfg=0x...`。`fault/raw` 保留原测量结果；`wiring` 是清除旧标志后，
执行独立检测周期得到的寄存器 0x07。只有 `test=0` 时 `wiring` 才可用于分析；
正常完成后的 `cfg` 应是 0x91。`wiring=0` 不能保证全部模拟电路正常。
这项检测不需要修改外部接线，也不需要用表笔带电探测芯片引脚。
